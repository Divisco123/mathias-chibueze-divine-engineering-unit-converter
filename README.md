Engineering Unit Converter

What it does

The Engineering Unit Converter is a Python-based program designed to convert common engineering measurements from one unit to another.

It supports four measurement categories: length, temperature, mass, and speed. Users can select a specific conversion from a fixed menu, enter a numerical value, and receive the converted result.

The program also includes a conversion history feature that allows users to view previous conversions.

How to run it

1. Install Python 3 or use an Android Python application such as Pydroid 3.
2. Download or clone this repository.
3. Open "engineering_unit_converter.py" in your Python editor.
4. Run the program using:

python engineering_unit_converter.py

5. Follow the menu instructions, select the conversion you want, and enter your measurement.

Conversions supported

Measurement| Conversion
Length| Millimetres (mm) to Inches
Length| Inches to Millimetres (mm)
Temperature| Celsius (°C) to Fahrenheit (°F)
Temperature| Fahrenheit (°F) to Celsius (°C)
Mass| Kilograms (kg) to Pounds (lb)
Mass| Pounds (lb) to Kilograms (kg)
Speed| Kilometres per hour (km/h) to Metres per second (m/s)
Speed| Metres per second (m/s) to Kilometres per hour (km/h)

My special features 

I added a Conversion History feature to make the program more useful.

The program stores successful conversions in a list while it is running. Users can select the history option to review their previous conversions without having to perform them again.
